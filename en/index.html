Frequently asked questions

Do I need to buy any device?

No. Viewifi uses the WiFi signal you already have at home. Any Android phone with WiFi works as a host.

Does it work in the dark or through walls?

Yes. The system senses how bodies distort WiFi radio waves, so it needs neither light nor line of sight.

Is my data safe?

Signal analysis runs entirely on the host phone. Only the alerts you configured leave towards your own Telegram bot — no third-party servers hold your data.

Can I watch more than one place?

Yes. Register several devices in Host mode under the same account and choose which one gets each command, or send them to all.

Can I use a Raspberry Pi or a Linux PC as the sensor?

Yes. Viewifi Host for Linux is a downloadable executable for PC (x86_64) and Raspberry Pi (ARM64). No Python required: run it and configure everything from a web panel in your browser at the device's IP address. It shares the same multi-host account and Telegram alerts as the app.

Is the app free?

Download the APK for free. Full functionality is available without subscriptions; optional premium features are coming soon.
