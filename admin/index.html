Precios de los planes

Wompi solo cobra en pesos colombianos: el importe en COP es el que se cobra de verdad. El de dólares es únicamente lo que se muestra en la web en inglés. Un cambio de precio afecta a las renovaciones siguientes, nunca a un periodo ya pagado.

Administradores

La lista de correos con permiso vive en el secreto ADMINS_PERMITIDOS de las Edge Functions, no aquí: así se cambia sin tocar la base de datos y sin pasar por este panel. Pero PostgreSQL no puede leer ese secreto, y las políticas de seguridad sí miran el rol guardado en la base de datos. Este botón pone las dos cosas de acuerdo.
